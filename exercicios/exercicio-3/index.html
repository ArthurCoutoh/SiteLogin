Sistema de Reservas de Cinema

Escreva uma aplicação que simule um sistema de reservas de um cinema. O cinema tem uma sala com 10 fileiras e 15 assentos por fileira. O programa deve:

  1. Representar os assentos:
    • Use uma matriz bidimensional bool[10, 15] para representar os assentos do cinema.
    • true indica que o assento está ocupado.
    • false indica que o assento está livre.
  2. Menu principal:

    Exibir um menu com as seguintes opções:

    • 1 - Visualizar Mapa de Assentos: Mostra o estado atual dos assentos (livres ou ocupados). Use caracteres como [_] para livre e [O] para ocupado.
    • 2 - Reservar Assento: Solicita ao usuário que escolha uma fileira (0-9) e um assento (0-14). Se o assento estiver livre, o programa deve marcá-lo como ocupado e exibir uma mensagem de sucesso. Se o assento estiver ocupado, o programa deve exibir uma mensagem informando que o assento está indisponível.
    • 3 - Cancelar Reserva: Solicita ao usuário que escolha uma fileira (0-9) e um assento (0-14). Se o assento estiver ocupado, o programa deve marcá-lo como livre e exibir uma mensagem de sucesso. Se o assento estiver livre, o programa deve exibir uma mensagem informando que o assento já está livre.
    • 4 - Relatório de Reservas:
      • Calcula e exibe a quantidade total de assentos livres. (Criar uma função para isso).
      • Calcula e exibe a quantidade total de assentos ocupados. (Criar uma função para isso).
      • Calcula e exibe a porcentagem de ocupação do cinema. (Criar uma função para isso).
    • 5 - Sair: Encerra o programa.
  3. Funções auxiliares:
    • Crie funções separadas para cada uma das operações do menu (visualizar mapa, reservar, cancelar, relatório). Isso ajudará a organizar o código e torná-lo mais legível.
  4. Validação:
    • O programa deve garantir que o usuário insira números válidos para fileiras e assentos.
    • O programa não deve permitir a reserva de um assento já ocupado ou o cancelamento de um assento já livre.

Estruturas a praticar

if / else, switch case, while, for, matrizes, funções.

Validação: o que usar

Use int.TryParse para fileira, assento e menu. Com if / else, confira fileira 0–9 e assento 0–14 antes de acessar a matriz; verifique o bool para reservar ou cancelar. Use while para entradas inválidas e para o menu.

Dicas

  • Use loops for aninhados para percorrer a matriz de assentos.
  • Use um loop while para manter o menu principal ativo até que o usuário escolha sair.
  • Use Console.ReadLine() e Convert.ToInt32() para obter a entrada do usuário.
  • Use Console.WriteLine() para formatar a saída, especialmente para exibir o mapa de assentos de forma clara.
  • Use switch para lidar com as opções do menu.
  • …e lembre-se: os índices das matrizes em C# começam em 0.
