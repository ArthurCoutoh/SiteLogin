Gerador de Tabuada com Intervalo

Escreva uma aplicação em C# que faça o seguinte:

1. Entrada

Solicite um número inteiro para a tabuada, um multiplicador inicial e um multiplicador final. Use valores entre -100 e 100 para cada entrada.

2. Processamento

Exiba a multiplicação para cada inteiro do intervalo, incluindo os limites. O multiplicador inicial não pode ser maior que o final.

3. Saída

Mostre cada operação no formato número × multiplicador = resultado e, ao final, a quantidade de operações realizadas.

4. Validação

Recuse entradas não inteiras, valores fora dos limites e intervalos invertidos. Se os limites forem iguais, apresente uma única operação.

Estruturas a praticar

for, if / else.

Validação: o que usar

Use int.TryParse para número e limites; if / else para o intervalo -100 a 100 e início menor ou igual ao fim. Repita entradas inválidas com while; use for para produzir a tabuada.

Exemplo de interação

Número: 7
Multiplicador inicial: 2
Multiplicador final: 4
7 × 2 = 14
7 × 3 = 21
7 × 4 = 28
Operações realizadas: 3

Dicas

  • Use for para percorrer o intervalo.
  • Inclua o limite final na condição.
  • Teste um intervalo com números negativos e outro com limites iguais.
