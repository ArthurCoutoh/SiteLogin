EXERCÍCIO 18 / C#

Fácil

Calendário de Anos Bissextos

Escreva uma aplicação de console em C#. Objetivo: combine condições lógicas para verificar as regras do ano bissexto.

Estruturas a praticar

if / else. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia um ano de 1 a 9999. Use as regras do calendário gregoriano para todos os anos aceitos neste exercício.
  2. Um ano é bissexto se for divisível por 400, ou se for divisível por 4 e não por 100.
  3. Com if / else, mostre se é bissexto e se fevereiro tem 28 ou 29 dias. Use % para verificar divisibilidade.

Validação: o que usar

Use int.TryParse e if / else para validar o intervalo; uma entrada inválida deve mostrar erro e encerrar. Teste 1900, 2000 e 2024 para verificar os limites das regras.

Exemplo de interação

Ano: 1900
Não bissexto. Fevereiro: 28 dias.
Ano: 2000
Bissexto. Fevereiro: 29 dias.

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
