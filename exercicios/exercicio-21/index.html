EXERCÍCIO 21 / C#

Médio

Monitor de Chuva Semanal

Escreva uma aplicação de console em C#. Objetivo: analise sete medições de chuva e identifique a maior sequência de dias secos.

Estruturas a praticar

for, if / else, vetores. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia sete medições em milímetros para double[7], de 0 a 1000; índice 0 representa segunda-feira.
  2. Use for para calcular total semanal, média diária e todos os dias empatados com a maior medição. Compare valores informados diretamente para os empates.
  3. Conte dias secos (medição zero) e calcule a maior sequência consecutiva de dias secos. A sequência não deve juntar domingo com segunda-feira.

Validação: o que usar

Use double.TryParse; rejeite double.IsNaN, double.IsInfinity e valores fora do intervalo com if / else. Repita a medição inválida sem avançar o índice. Para medir a sequência, use um contador atual e um máximo.

Exemplo de interação

Medições: 0, 0, 10, 5, 0, 0, 0
Total: 15,00 mm
Média: 2,14 mm
Maior medição: quarta-feira, 10,00 mm
Dias secos: 5
Maior sequência seca: 3 dias

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
