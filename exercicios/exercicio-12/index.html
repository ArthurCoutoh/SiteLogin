EXERCÍCIO 12 / C#

Fácil

Agenda dos Dias da Semana

Escreva uma aplicação de console em C#. Objetivo: associe um número da semana a um dia e a uma atividade de estudo.

Estruturas a praticar

switch case. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia um inteiro de 1 a 7, representando segunda a domingo.
  2. Use switch case para mostrar: 1 lógica; 2 variáveis; 3 condições; 4 switch; 5 laços; 6 revisão; 7 descanso. Mostre também o nome do dia.
  3. Use default para indicar opção fora do intervalo. Cada case precisa terminar corretamente com break.

Validação: o que usar

Use int.TryParse para evitar erro com letras; use default do switch para inteiros que não estejam entre 1 e 7. Uma entrada inválida encerra a execução após a mensagem.

Exemplo de interação

Dia: 4
Quinta-feira — Estudar switch case.

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
