EXERCÍCIO 23 / C#

Médio

Verificador de Palíndromos

Escreva uma aplicação de console em C#. Objetivo: compare os extremos de um texto ignorando espaços e diferenças de caixa.

Estruturas a praticar

for, if / else, strings. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia um texto de até 100 caracteres. Neste exercício aceite somente letras sem acento A–Z/a–z e espaços comuns.
  2. Remova espaços comuns com Replace(" ", "") e converta com ToLowerInvariant(). Não aceite resultado vazio.
  3. Use for com dois índices, um no início e outro no final, para comparar os caracteres. Mostre o texto normalizado e se é palíndromo. Não use Reverse.

Validação: o que usar

Use string.IsNullOrWhiteSpace para texto vazio, .Length para limite e for com if / else para conferir cada caractere permitido. Peça novamente com while se houver números, símbolos ou acentos.

Exemplo de interação

Texto: A sacada da casa
Normalizado: asacadadacasa
É palíndromo.

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
