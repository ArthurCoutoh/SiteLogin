EXERCÍCIO 28 / C#

Difícil

Verificador de um Sudoku 4×4

Escreva uma aplicação de console em C#. Objetivo: verifique linhas, colunas e blocos de um tabuleiro preenchido.

Estruturas a praticar

for, if / else, matrizes, funções. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia 16 inteiros de 1 a 4 em int[4,4]. O tabuleiro está completamente preenchido: não aceite zero.
  2. Cada linha e coluna deve conter 1, 2, 3 e 4 sem repetição. Cada um dos quatro blocos 2×2 também deve seguir essa regra.
  3. Crie funções para verificar linhas, colunas e blocos, usando for e um vetor bool[5] reiniciado a cada grupo. Não é necessário resolver o Sudoku.
  4. Mostre se o tabuleiro é válido. Se inválido, liste todas as linhas, colunas e blocos com repetição, numerados de 1 a 4; blocos em ordem de leitura.

Validação: o que usar

Use int.TryParse e if / else para números entre 1 e 4, repetindo o campo inválido. Números repetidos são aceitos na leitura para que o relatório detecte o problema; não os rejeite antes da análise.

Exemplo de interação

1 2 3 4
3 4 1 2
2 1 4 3
4 3 2 1
Resultado: Sudoku válido.

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
