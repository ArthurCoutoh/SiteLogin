Difícil

Caixa de Troco com Cédulas Limitadas

Escreva uma aplicação de console em C#. Objetivo: procure uma combinação exata de troco respeitando o estoque de cédulas.

Estruturas a praticar

for, if / else, vetores, funções. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Use int[4] com valores 20, 10, 5 e 2 e outro vetor com as quantidades disponíveis (0–10 por valor). Leia um troco inteiro entre 0 e 200.
  2. Use quatro for aninhados para testar todas as combinações possíveis dentro do estoque. Não basta sempre escolher a maior cédula: é preciso procurar uma solução exata.
  3. Entre soluções exatas, escolha a com menor número de cédulas. Se empatar, prefira mais cédulas de 20, depois de 10, depois de 5. Mostre a combinação e diminua o estoque apenas após encontrar a solução.
  4. Crie uma função para procurar a combinação e outra para exibir resultado. Se não houver solução, informe e preserve o estoque; troco zero usa zero cédulas.

Validação: o que usar

Use int.TryParse e if / else para estoque e troco. Solicite novamente campos inválidos. Guarde a melhor combinação em um vetor separado; não reduza o estoque durante a busca.

Exemplo de interação

Estoque: 20→0, 10→0, 5→1, 2→3
Troco: 6
Cédulas de 2: 3
Total de cédulas: 3
Estoque restante de 2: 0

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
