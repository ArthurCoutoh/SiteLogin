EXERCÍCIO 15 / C#

Fácil

Tentativas de uma Senha Didática

Escreva uma aplicação de console em C#. Objetivo: controle até três tentativas e diferencie sucesso de bloqueio.

Estruturas a praticar

do while, if / else, strings. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Defina a senha de teste como aula123. Este é um exercício de laços, não um sistema real de autenticação.
  2. Use do while para pedir a senha e compare com ==, respeitando maiúsculas e minúsculas.
  3. Conte toda entrada como tentativa, inclusive vazia. Encerre ao acertar ou completar três tentativas; informe tentativas usadas no sucesso ou bloqueio na terceira falha.

Validação: o que usar

Use string.IsNullOrWhiteSpace dentro de if para identificar entrada vazia e tratá-la como tentativa incorreta. Não remova espaços da senha com Trim: a comparação deve ser exata.

Exemplo de interação

Tentativa 1: teste
Senha incorreta.
Tentativa 2: aula123
Acesso permitido após 2 tentativas.

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
