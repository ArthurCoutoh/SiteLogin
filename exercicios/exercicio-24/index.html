EXERCÍCIO 24 / C#

Médio

Conversão de Decimal para Binário

Escreva uma aplicação de console em C#. Objetivo: construa uma representação binária usando divisões sucessivas.

Estruturas a praticar

while, if / else, strings. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia um inteiro de 0 a 65535 e preserve o valor original.
  2. Use while, divisão inteira por 2 e resto % 2 para montar os dígitos binários na ordem correta. Não use Convert.ToString(numero, 2).
  3. Trate zero separadamente com if / else. Mostre decimal, binário e quantidade de dígitos iguais a 1.

Validação: o que usar

Use int.TryParse e if / else para o intervalo. Solicite novamente com while se inválido. A representação de zero deve ser 0, com zero bits iguais a 1.

Exemplo de interação

Decimal: 13
Binário: 1101
Quantidade de bits 1: 3

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
