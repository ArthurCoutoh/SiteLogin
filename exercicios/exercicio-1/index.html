Conversor e Analisador de Temperatura

Escreva uma aplicação que faça o seguinte:

  1. Entrada: Solicite ao usuário que insira uma temperatura em Celsius.
  2. Conversão:
    • Converta a temperatura Celsius para Fahrenheit usando a fórmula: Fahrenheit = (Celsius * 9/5) + 32
    • Converta a temperatura Celsius para Kelvin usando a fórmula: Kelvin = Celsius + 273.15
  3. Análise:
    • Determine se a temperatura Celsius inserida está abaixo do ponto de congelamento (0°C), acima do ponto de ebulição (100°C) ou dentro da faixa normal.
  4. Saída:
    • Exiba a temperatura Celsius original.
    • Exiba as temperaturas Fahrenheit e Kelvin convertidas.
    • Exiba uma mensagem indicando se a temperatura está abaixo do ponto de congelamento, acima do ponto de ebulição ou dentro da faixa normal.

Estruturas a praticar

if / else.

Validação: o que usar

Use double.TryParse para a temperatura; com if / else, rejeite entradas não numéricas, double.IsNaN e double.IsInfinity antes de converter. Use if / else if / else para as faixas.

Exemplo de interação

Digite a temperatura em Celsius: 25
Celsius: 25
Fahrenheit: 77
Kelvin: 298.15
A temperatura está dentro da faixa normal.

Digite a temperatura em Celsius: -10
Celsius: -10
Fahrenheit: 14
Kelvin: 263.15
A temperatura está abaixo do ponto de congelamento.

Dicas

  • Use double ou float para armazenar os valores de temperatura.
  • Use instruções if/else if/else para análise de temperatura.
  • Use double.Parse() ou float.Parse() para converter a string de entrada para um número.
