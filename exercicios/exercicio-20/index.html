Tarifa de Pedágio por Categoria

Escreva uma aplicação de console em C#. Objetivo: escolha uma tarifa por categoria e calcule o preço para caminhões por eixo.

Estruturas a praticar

switch case, if / else. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia a categoria: 1 motocicleta, 2 automóvel, 3 caminhão.
  2. Use switch case: moto R$ 4,50; automóvel R$ 9,00; caminhão R$ 7,00 por eixo. Somente para caminhão, solicite quantidade de eixos de 2 a 9.
  3. Use decimal para dinheiro. Mostre categoria e valor com duas casas decimais; não aplique descontos.

Validação: o que usar

Use int.TryParse para categoria e eixos, default para categoria desconhecida e if / else para limites dos eixos. Repita entradas inválidas com while; não peça eixos nas demais categorias.

Exemplo de interação

Categoria: 3
Eixos: 4
Caminhão — Tarifa: R$ 28,00

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
