Fácil

Classificador de Triângulos

Escreva uma aplicação de console em C#. Objetivo: verifique se três lados formam um triângulo e classifique seus lados.

Estruturas a praticar

if / else. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia três comprimentos inteiros entre 1 e 10000.
  2. Só existe triângulo quando a soma de quaisquer dois lados é maior que o terceiro. Valide isso antes de classificar.
  3. Use if / else if / else: três lados iguais = equilátero; exatamente dois iguais = isósceles; todos diferentes = escaleno. Mostre também o perímetro quando existir triângulo.

Validação: o que usar

Use int.TryParse e if / else para os valores positivos e o limite. Inteiros evitam problemas de igualdade aproximada neste exercício. Em entrada inválida, informe erro e encerre.

Exemplo de interação

Lados: 5, 5, 8
Triângulo isósceles
Perímetro: 18
Lados: 1, 2, 3
Não forma triângulo.

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
