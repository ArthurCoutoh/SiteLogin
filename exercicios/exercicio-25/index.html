EXERCÍCIO 25 / C#

Fácil

Duração de uma Atividade

Escreva uma aplicação de console em C#. Objetivo: calcule a duração entre dois horários, inclusive atravessando a meia-noite.

Estruturas a praticar

if / else. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia hora e minuto de início e fim como quatro inteiros. Horas: 0–23; minutos: 0–59.
  2. Converta cada horário para minutos desde a meia-noite. Se o fim for menor que o início, considere o dia seguinte.
  3. Horários iguais significam duração zero. A atividade dura menos de 24 horas. Mostre a duração em horas completas e minutos restantes.

Validação: o que usar

Use int.TryParse e if / else para os quatro campos. Repita somente o campo inválido com while. Use divisão inteira e % 60 para separar horas e minutos do resultado.

Exemplo de interação

Início: 23:40
Fim: 01:15
Duração: 1 hora e 35 minutos

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
