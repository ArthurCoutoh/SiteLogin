EXERCÍCIO 2 / C#

Médio

Loja de Produtos - Gerenciamento de Estoque

Escreva uma aplicação para gerenciar o estoque de uma pequena loja que vende 4 tipos de produtos. O programa deve:

  1. Armazenar dados:
    • Criar uma matriz bidimensional (4x3) onde cada linha representa um produto.
    • A primeira coluna deve armazenar a quantidade em estoque do produto (inteiro).
    • A segunda coluna deve armazenar o preço unitário do produto (double).
    • A terceira coluna deve armazenar o número de vendas daquele produto (inteiro).
  2. Interação com o usuário:

    Criar um menu com as seguintes opções:

    • 1 - Adicionar Estoque: Permite ao usuário escolher um produto (pelo índice da linha) e adicionar uma quantidade ao estoque.
    • 2 - Registrar Venda: Permite ao usuário escolher um produto e registrar uma venda, diminuindo a quantidade em estoque e incrementando o número de vendas. A venda só pode ser efetuada se houver estoque suficiente.
    • 3 - Consultar Estoque: Exibe a matriz de estoque formatada, mostrando a quantidade, o preço unitário e o número de vendas de cada produto.
    • 4 - Relatório:
      • Calcula e exibe o valor total do estoque (soma do valor de cada produto: quantidade × preço unitário). (Criar uma função para isso).
      • Calcula e exibe o total de vendas realizadas (soma do número de vendas de todos os produtos). (Criar uma função para isso).
      • Encontra e exibe o produto mais vendido (aquele com o maior número de vendas). (Criar uma função para isso).
      • Encontra e exibe o produto com maior valor em estoque (quantidade × preço unitário). (Criar uma função para isso).
    • 5 - Sair: Encerra o programa.
  3. Validação:
    • O programa não deve permitir a venda de produtos sem estoque suficiente.

Estruturas a praticar

if / else, switch case, do while, for, matrizes, funções.

Validação: o que usar

Use int.TryParse para índices, quantidades, vendas e opções; double.TryParse para preços. Rejeite double.IsNaN e double.IsInfinity, preços negativos e quantidades não positivas. Use if / else para índices entre 0 e 3 e estoque suficiente; do while para o menu e while para repetir campos inválidos. Inicialize os quatro preços e os estoques antes do menu.

Dicas

  • Use loops for para percorrer a matriz.
  • Use Console.ReadLine(), Convert.ToInt32() e Convert.ToDouble() para obter a entrada do usuário, com tratamento de erros.
  • Use um loop do-while para manter o menu ativo até que o usuário escolha sair.
  • Use switch para lidar com as opções do menu.
  • Use double[,] para os dados do estoque, pois precisamos armazenar números inteiros (quantidade e número de vendas) e números de ponto flutuante (preço unitário).
