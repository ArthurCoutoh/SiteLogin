EXERCÍCIO 13 / C#

Fácil

Calculadora com Menu de Operações

Escreva uma aplicação de console em C#. Objetivo: repita um menu de quatro operações e trate a divisão por zero.

Estruturas a praticar

switch case, do while, if / else. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Use do while para mostrar 1 somar, 2 subtrair, 3 multiplicar, 4 dividir e 0 sair.
  2. Nas opções 1 a 4, solicite dois double e use switch case para selecionar a operação. Não peça operandos ao escolher 0.
  3. Mostre o resultado com duas casas decimais. Na divisão, use if / else para bloquear divisor igual a zero e retorne ao menu.

Validação: o que usar

Use int.TryParse no menu e double.TryParse nos operandos. Rejeite double.IsNaN e double.IsInfinity. Solicite novamente o campo inválido com while. Se o resultado não for finito, mostre erro sem apresentá-lo como resultado válido.

Exemplo de interação

Opção: 4
Primeiro número: 8
Segundo número: 2
Resultado: 4,00
Opção: 0
Programa encerrado.

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
