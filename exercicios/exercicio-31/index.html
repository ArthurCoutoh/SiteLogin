EXERCÍCIO 31 / C#

Médio

Calculadora de Juros Simples e Compostos

Crie uma aplicação de console em C# que solicite um capital inicial, uma taxa de juros, o período da taxa e um prazo. Mostre os juros e o montante final pelos regimes de juros simples e compostos.

Estruturas a praticar

if / else, switch case, while, funções e, opcionalmente, Regex.

Entradas e regras

  1. Peça o capital inicial (valor em reais), maior que zero.
  2. Peça a taxa de juros em porcentagem: por exemplo, 2 significa 2%, e não 0,02. Aceite taxa zero, mas rejeite valores negativos.
  3. Peça se a taxa é ao dia, ao mês ou ao ano. Você pode começar com um menu: 1 = ao ano, 2 = ao mês, 3 = ao dia. Use switch case e default para validar a opção.
  4. Depois de escolher o período, peça um prazo inteiro maior que zero naquela mesma unidade: taxa ao mês → prazo em meses; taxa ao dia → prazo em dias; taxa ao ano → prazo em anos. Não misture unidades nem faça conversões de taxas neste exercício.
  5. Calcule os dois resultados com os mesmos dados. Exiba capital, taxa e sua unidade, prazo, juros e montante em cada regime. Mostre também a diferença entre os montantes.
  6. Se uma entrada for inválida, explique o erro e peça novamente com while, sem encerrar o programa.

Fórmulas

C = capital inicial
i = taxa informada / 100
t = prazo na mesma unidade da taxa

Juros simples:
J = C * i * t
M = C + J

Juros compostos:
M = C * Math.Pow(1 + i, t)
J = M - C

Crie funções separadas para os cálculos. Use double com Math.Pow; não use ^ como potência em C#. Faça os cálculos sem arredondar resultados intermediários e formate a saída com duas casas decimais.

Dica opcional: escolher o período por texto

Em vez do menu numérico, você pode pedir uma palavra. Nesta alternativa, aceite somente estas oito formas: dia, Dia, Mês, mes, mês, Mes, ano e Ano.

Use o código abaixo para validar a entrada. A Regex confere a palavra inteira e diferencia maiúsculas e minúsculas. Não use RegexOptions.IgnoreCase nem Trim() antes da validação se quiser aceitar exatamente a lista: DIA, ANO, MES, espaços extras e palavras com letras a mais devem ser recusados.

using System.Text.RegularExpressions;

string periodo;
while (true)
{
    Console.Write("Período da taxa (dia, mês ou ano): ");
    string? entrada = Console.ReadLine();

    if (entrada is null)
    {
        Console.WriteLine("Entrada encerrada.");
        return;
    }

    if (!Regex.IsMatch(entrada, @"\A(?:dia|Dia|Mês|mes|mês|Mes|ano|Ano)\z"))
    {
        Console.WriteLine("Período inválido. Digite dia, mês ou ano.");
        continue;
    }

    // Normalize somente depois de validar.
    periodo = entrada.ToLowerInvariant();
    if (periodo == "mes")
        periodo = "mês";

    break;
}

string unidadePrazo = periodo switch
{
    "dia" => "dias",
    "mês" => "meses",
    "ano" => "anos",
    _ => throw new InvalidOperationException("Período inválido.")
};

Console.Write($"Prazo em {unidadePrazo}: ");
// Agora leia e valide o prazo para continuar o cálculo.

Validação: o que usar

Use double.TryParse para capital e taxa e int.TryParse para o prazo. Use if / else para verificar os limites e double.IsFinite para rejeitar NaN, infinito e resultados que ultrapassem a capacidade do tipo. Para aceitar vírgula decimal, use explicitamente a cultura pt-BR, por exemplo:

using System.Globalization;

var cultura = CultureInfo.GetCultureInfo("pt-BR");
bool valido = double.TryParse(
    Console.ReadLine(),
    NumberStyles.AllowDecimalPoint | NumberStyles.AllowLeadingSign,
    cultura,
    out double capital
) && double.IsFinite(capital) && capital > 0;

Adapte a condição para a taxa (>= 0). Para o prazo, valide com int.TryParse e prazo > 0. Se o cálculo resultar em um número não finito, informe que os valores são grandes demais.

Exemplo de interação

Capital inicial (R$): 1000
Taxa de juros (%): 2
Período da taxa (dia, mês ou ano): mês
Prazo em meses: 3

Capital: R$ 1.000,00
Taxa: 2,00% ao mês
Prazo: 3 meses

Juros simples: R$ 60,00
Montante simples: R$ 1.060,00

Juros compostos: R$ 61,21
Montante composto: R$ 1.061,21

Diferença entre os montantes: R$ 1,21

Como conferir

  • Com taxa zero, ambos os montantes devem ser iguais ao capital.
  • Com prazo de um período, os dois regimes devem produzir o mesmo montante.
  • Com capital 1000, taxa 10% ao ano e prazo de 2 anos, confira R$ 1.200,00 no simples e R$ 1.210,00 no composto.
  • Teste todas as oito formas aceitas e rejeite vazio, espaços, dias, MÊS, Diaa e um texto com quebra de linha ao final.
  • Teste números inválidos, capital negativo, taxa negativa e prazo zero.
