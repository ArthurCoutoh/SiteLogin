EXERCÍCIO 17 / C#

Médio

Números Primos em um Intervalo

Escreva uma aplicação de console em C#. Objetivo: teste divisibilidade e liste os primos entre dois limites.

Estruturas a praticar

for, if / else. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia início e fim inteiros entre 1 e 1000, com início menor ou igual ao fim.
  2. Use um for para percorrer o intervalo e outro for para testar divisores de cada candidato. Pode interromper o teste com break ao encontrar um divisor.
  3. Mostre os números primos, a quantidade e sua soma. Se não houver primo, mostre uma mensagem. Lembre que 1 não é primo.

Validação: o que usar

Use int.TryParse; valide limites e ordem com if / else antes dos laços. Em caso de erro, peça os dois limites novamente com while. Não use uma lista pronta de primos.

Exemplo de interação

Início: 10
Fim: 20
Primos: 11, 13, 17, 19
Quantidade: 4
Soma: 60

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
