EXERCÍCIO 11 / C#

Fácil

Controle de Acesso por Idade

Escreva uma aplicação de console em C#. Objetivo: decida se uma pessoa pode entrar em uma sessão com classificação etária escolhida.

Estruturas a praticar

if / else. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia o nome do visitante, a idade (0 a 120) e a classificação da sessão (0, 10, 12, 14, 16 ou 18).
  2. Com if / else, autorize a entrada quando a idade for maior ou igual à classificação; caso contrário, negue. Não considere acompanhantes neste exercício.
  3. Mostre nome, idade, classificação e resultado. Não crie menu: processe um visitante por execução.

Validação: o que usar

Use string.IsNullOrWhiteSpace(nome) dentro de if para recusar nome vazio; letras e espaços internos são permitidos. Use int.TryParse e if / else para idade e classificação. Se inválido, informe o erro e encerre sem calcular.

Exemplo de interação

Nome: Joana
Idade: 15
Classificação: 16
Joana: entrada não autorizada.

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
