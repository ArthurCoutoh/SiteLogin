EXERCÍCIO 8 / C#

Médio

Sistema de Votação da Turma

Escreva uma aplicação em C# que faça o seguinte:

1. Armazenamento

Cadastre os nomes de três candidatos em string[3]. Use int[3] para seus votos e variáveis separadas para votos brancos e nulos.

2. Menu

  • 1 — Registrar voto: mostre os candidatos de 1 a 3; 0 representa voto branco e qualquer outro inteiro representa voto nulo.
  • 2 — Consultar apuração: mostre os votos de cada candidato, brancos, nulos e total de votos registrados.
  • 3 — Relatório: apresente o percentual de cada candidato em relação aos votos válidos, os percentuais de brancos e nulos em relação ao total e os candidatos mais votados.
  • 4 — Sair.

3. Regras

Votos válidos são apenas os recebidos pelos candidatos. Se houver empate no maior número de votos válidos, mostre todos os candidatos empatados. Se não houver votos válidos, informe que não há candidato vencedor.

4. Funções e validação

Crie funções para registrar votos, calcular percentuais e exibir o relatório. Não divida por zero. Entrada que não possa ser convertida para inteiro deve ser solicitada novamente, sem registrar voto.

Estruturas a praticar

for, if / else, switch case, do while, vetores, funções.

Validação: o que usar

Use string.IsNullOrWhiteSpace para os nomes dos candidatos e Trim após validar. Use int.TryParse para voto e menu; while para repetir entrada não numérica sem registrar voto. Use if / else para impedir divisão por zero; do while com switch case para o menu. Um inteiro fora de 0–3 é voto nulo, não erro de conversão.

Exemplo de interação

Bruno: 2 votos

Brancos: 1

Mais votada: Ana

Dicas

  • Use switch para as opções do menu.
  • Use for para percorrer os candidatos.
  • Diferencie uma opção inválida do menu de um voto nulo.
