Fácil

Calculadora e Classificador de IMC

Escreva uma aplicação em C# que faça o seguinte:

1. Entrada

Solicite o peso em quilogramas e a altura em metros de uma pessoa adulta. Use double.

2. Cálculo

Calcule IMC = peso / (altura * altura).

3. Classificação

  • IMC menor que 18,5: abaixo do peso.
  • De 18,5 até menos de 25: faixa adequada.
  • De 25 até menos de 30: sobrepeso.
  • De 30 até menos de 35: obesidade grau I.
  • De 35 até menos de 40: obesidade grau II.
  • A partir de 40: obesidade grau III.

4. Saída e validação

Mostre o IMC com duas casas decimais e a classificação. Classifique usando o resultado original, antes do arredondamento da exibição. Aceite somente números positivos e finitos; solicite novamente entradas inválidas. As faixas são regras deste exercício de programação.

Estruturas a praticar

if / else, while.

Validação: o que usar

Use double.TryParse para peso e altura; if / else para valores positivos e rejeição de double.IsNaN e double.IsInfinity. Use while para repetir dados inválidos antes do cálculo. Se o IMC calculado não for finito, informe erro e peça valores novamente.

Exemplo de interação

Peso (kg): 70
Altura (m): 1,75
IMC: 22,86
Classificação: faixa adequada.

Dicas

  • Use if/else if/else em ordem crescente das faixas.
  • Não confunda centímetros com metros.
  • Nunca divida por uma altura igual a zero.
