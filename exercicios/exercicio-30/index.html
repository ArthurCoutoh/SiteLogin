EXERCÍCIO 30 / C#

Médio

Fila de Atendimento Circular

Escreva uma aplicação de console em C#. Objetivo: atenda pessoas por ordem de chegada e reutilize posições de um vetor.

Estruturas a praticar

switch case, do while, if / else, vetores. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Use string[5], índice da próxima entrada, índice do próximo atendimento e contador de pessoas. Todos começam em zero.
  2. Use do while e switch case: 1 adicionar pessoa; 2 atender próxima; 3 mostrar fila na ordem de atendimento; 0 sair.
  3. Ao adicionar ou atender, avance o índice correspondente com % 5. Mostre a posição na fila de cada pessoa na consulta, começando em 1.
  4. Fila cheia bloqueia novas entradas; fila vazia bloqueia atendimento. Permita nomes repetidos; só valide nome ao adicionar quando houver espaço. Não desloque os elementos do vetor.

Validação: o que usar

Use string.IsNullOrWhiteSpace e Trim para o nome; letras e espaços internos são permitidos. Use int.TryParse e default para opções inválidas. Peça novamente nome vazio com while; valide capacidade com if / else antes de modificar o vetor.

Exemplo de interação

Adicionar: Ana
Adicionar: Bruno
Atender: Ana
Fila: 1 — Bruno
Pessoas aguardando: 1

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
