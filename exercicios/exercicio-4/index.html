Fácil

Calculadora de Compra com Desconto

Escreva uma aplicação em C# que faça o seguinte:

1. Entrada

  • Solicite o nome do produto, o preço unitário e a quantidade comprada.
  • Use decimal para o preço e int para a quantidade.

2. Cálculo e classificação

  • Calcule o subtotal: preço unitário × quantidade.
  • Aplique 10% de desconto quando o subtotal for maior ou igual a R$ 200,00. Para subtotais menores, não aplique desconto.
  • Calcule o valor do desconto e o total a pagar.

3. Saída

Mostre o produto, o subtotal, a porcentagem aplicada, o desconto em reais e o total a pagar, com duas casas decimais.

4. Validação

Não aceite nome vazio, preço menor ou igual a zero ou quantidade menor ou igual a zero. Solicite novamente os dados inválidos.

Estruturas a praticar

if / else, while.

Validação: o que usar

Use string.IsNullOrWhiteSpace(nomeProduto) dentro de if para detectar null, texto vazio ou apenas espaços. Letras são válidas em um nome de produto; não as rejeite. Use Trim após validar. Use decimal.TryParse para preço e int.TryParse para quantidade; if / else para exigir valores maiores que zero, e while para repetir cada campo inválido.

Exemplo de interação

Produto: Caderno
Preço unitário: 25,00
Quantidade: 8
Subtotal: R$ 200,00
Desconto: 10% — R$ 20,00
Total: R$ 180,00

Dicas

  • Use if/else para escolher o desconto.
  • A taxa de 10% corresponde a 0.10m em uma expressão com decimal.
  • Teste subtotais de R$ 199,99, R$ 200,00 e R$ 200,01.
