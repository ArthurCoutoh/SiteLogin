Fácil

Divisores de um Número

Escreva uma aplicação de console em C#. Objetivo: liste divisores positivos e descubra se um número é perfeito.

Estruturas a praticar

for, if / else. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia um inteiro entre 1 e 10000.
  2. Use for de 1 até o número e if com o operador % para mostrar todos os divisores positivos, em ordem crescente.
  3. Some apenas os divisores menores que o número. Um número é perfeito quando essa soma é igual ao próprio número. Exiba também a quantidade total de divisores.

Validação: o que usar

Use int.TryParse e if / else para validar o intervalo; repita a entrada com while. Para 1, a soma dos divisores próprios é zero, portanto ele não é perfeito.

Exemplo de interação

Número: 6
Divisores: 1, 2, 3, 6
Quantidade: 4
Soma dos divisores próprios: 6
Número perfeito.

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
