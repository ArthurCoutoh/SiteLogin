EXERCÍCIO 22 / C#

Médio

Analisador de Caracteres de uma Frase

Escreva uma aplicação de console em C#. Objetivo: conte letras, vogais, dígitos e espaços percorrendo uma frase.

Estruturas a praticar

foreach, if / else, strings. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia uma frase de 1 a 200 caracteres, contendo ao menos um caractere que não seja espaço. Não use Trim na frase analisada.
  2. Percorra com foreach. Conte letras com char.IsLetter, dígitos com char.IsDigit, espaços em branco com char.IsWhiteSpace e outros caracteres na categoria restante.
  3. Conte também vogais apenas a, e, i, o, u, sem acentos, em qualquer caixa; use char.ToLowerInvariant. A quantidade de vogais é uma parte da quantidade de letras, não uma quinta categoria independente.

Validação: o que usar

Use string.IsNullOrWhiteSpace e .Length com if / else para rejeitar frase vazia ou longa. Peça novamente com while. Uma vogal acentuada conta como letra, mas não como vogal sem acento neste exercício.

Exemplo de interação

Frase: Ola 123!
Letras: 3
Vogais sem acento: 2
Dígitos: 3
Espaços em branco: 1
Outros: 1

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
