EXERCÍCIO 27 / C#

Médio

Tradutor de Letras para Morse

Escreva uma aplicação de console em C#. Objetivo: traduza A a F para código Morse e preserve separações entre palavras.

Estruturas a praticar

switch case, foreach, if / else, strings. Use as estruturas indicadas para implementar as regras.

Requisitos

  1. Leia uma mensagem de até 60 caracteres contendo apenas letras A a F (em qualquer caixa) e espaços comuns. Exija pelo menos uma letra.
  2. Percorra com foreach e use switch case: A .-, B -..., C -.-., D -.., E ., F ..-. .
  3. Use um espaço entre códigos de letras e / entre palavras. Ignore espaços nas extremidades e trate vários espaços consecutivos como uma única separação. Mostre a mensagem normalizada e a tradução.

Validação: o que usar

Use string.IsNullOrWhiteSpace, .Length e ToUpperInvariant(). Valide caracteres com foreach e if / else antes de traduzir; qualquer outro caractere deve fazer a mensagem ser solicitada novamente com while.

Exemplo de interação

Mensagem: FACE
Morse: ..-. .- -.-. .
Mensagem: A B
Morse: .- / -...

Como conferir

  • Teste o exemplo, pelo menos uma entrada inválida e os limites dos intervalos informados.
  • Não avance contadores nem altere dados quando uma operação for recusada.
  • Os índices dos vetores e matrizes começam em zero; use os limites descritos no enunciado.
