APOIO 01 / C#

Variáveis

1. O que é lógica de programação?

É organizar passos para resolver um problema. Um algoritmo é essa sequência de passos; o programa expressa a sequência em uma linguagem que o computador pode executar. Antes de escrever código, defina quais dados entram, o que fazer com eles e qual resultado apresentar.

Para calcular o dobro de um número: leia o número (entrada), multiplique por dois (processamento) e mostre o resultado (saída). Execute os passos no papel com um valor conhecido antes de programar.

2. O que é uma variável?

É um espaço identificado por um nome, usado para armazenar um valor. Em C#, o tipo define quais valores podem ser guardados e quais operações fazem sentido. Você declara uma variável com tipo nome = valor;.

int idade = 18;
double altura = 1.75;
string nome = "Arthur";
char inicial = 'A';
bool matriculado = true;
TipoUsoExemplo
intNúmeros inteiros, como quantidadesint estoque = 10;
doubleNúmeros com parte decimaldouble temperatura = 25.5;
floatNúmero decimal com menor precisão que doublefloat altura = 1.75f;
decimalCálculos decimais, especialmente valores monetáriosdecimal preco = 12.50m;
stringTexto entre aspas duplasstring cidade = "Ji-Paraná";
charUm único caractere entre aspas simpleschar letra = 'B';
boolValor lógico: true ou falsebool ocupado = false;

No código C#, escreva o separador decimal como ponto. Uma entrada digitada no console pode usar outro separador, de acordo com a cultura configurada no computador. double e float podem apresentar pequenas aproximações; para dinheiro, normalmente prefira decimal.

3. Atribuir, atualizar e nomear

= atribui um valor. Ele não compara dois valores. A expressão à direita é calculada antes de o resultado ser armazenado à esquerda.

int pontos = 5;
pontos = pontos + 3; // Agora vale 8.
pontos += 2;        // Agora vale 10.
pontos++;           // Agora vale 11.
Console.WriteLine(pontos);

Use nomes claros, como quantidadeVendida. Nomes diferenciam maiúsculas de minúsculas: idade e Idade são diferentes. Não comece um nome por número, não use espaços e evite palavras reservadas, como if.

Uma constante não pode receber outro valor depois da declaração: const double PI = 3.14159;. Uma variável local precisa receber um valor antes de ser lida. Uma variável criada dentro de um bloco entre chaves normalmente só pode ser usada naquele bloco.

4. Operadores e ordem dos cálculos

OperadorOperaçãoResultado
+Soma5 + 2 → 7
-Subtração5 - 2 → 3
*Multiplicação5 * 2 → 10
/Divisão5.0 / 2 → 2.5
%Resto da divisão5 % 2 → 1

Multiplicação e divisão vêm antes de soma e subtração. Parênteses tornam a ordem explícita: (2 + 3) * 4 resulta em 20. Se os dois operandos forem inteiros, a divisão descarta a parte fracionária: 5 / 2 resulta em 2. Use um operando decimal, como 5.0 / 2, para obter 2.5.

5. Ler e mostrar dados

Console.Write() mostra um texto sem mudar de linha. Console.WriteLine() mostra o texto e passa para a próxima linha. Console.ReadLine() lê uma linha como texto; para calcular com a entrada, converta-a para o tipo numérico adequado.

Console.Write("Digite seu nome: ");
string nome = Console.ReadLine() ?? "";

Console.Write("Digite sua idade: ");
int idade = Convert.ToInt32(Console.ReadLine());

Console.WriteLine("Olá, " + nome);
Console.WriteLine($"No próximo ano você terá {idade + 1} anos.");

?? "" usa um texto vazio se a leitura não retornar um texto. A interpolação com $"...{variavel}..." insere valores dentro da mensagem. No exemplo, a conversão pressupõe uma idade válida; se a entrada não for válida, pode ocorrer um erro.

6. Validar uma conversão

Parse converte texto e pode lançar uma exceção quando o formato não é válido. TryParse informa se a conversão deu certo. Para aceitar somente uma idade inteira não negativa:

Console.Write("Digite sua idade: ");
int idade;
bool entradaValida = int.TryParse(Console.ReadLine(), out idade);

if (entradaValida && idade >= 0)
{
    Console.WriteLine($"Idade registrada: {idade}");
}
else
{
    Console.WriteLine("Digite um número inteiro não negativo.");
}

7. Teste de mesa e erros comuns

Um teste de mesa acompanha os valores a cada instrução. Se quantidade = 3 e preco = 8.5, o cálculo total = quantidade * preco deve produzir 25.5. Confira manualmente e compare com a saída.

  • Não confunda o texto "10" com o número 10: textos podem ser concatenados.
  • Verifique o tipo antes de calcular e converta entradas com cuidado.
  • Use ponto e vírgula no final das declarações e aspas corretas para texto e caractere.
  • Evite guardar um número decimal em int sem decidir como tratar a parte fracionária.

Pratique

Leia um nome, uma quantidade inteira e um preço decimal. Calcule o valor total e exiba uma mensagem com todos os dados. Teste quantidade zero, quantidade positiva e uma entrada inválida.
