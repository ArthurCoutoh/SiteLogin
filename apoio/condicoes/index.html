Estruturas de condição

1. Decisões no programa

Uma condição é uma expressão cujo resultado é true (verdadeiro) ou false (falso). Ela permite executar instruções somente em determinadas situações. Por exemplo: autorizar uma compra apenas quando o estoque for suficiente.

2. Comparações

OperadorSignificadoExemplo
==Igual aidade == 18
!=Diferente deopcao != 5
>Maior quenota > 7
<Menor quetemperatura < 0
>=Maior ou igual aestoque >= quantidade
<=Menor ou igual aidade <= 12

= atribui um valor; == compara valores. Os operadores > e < excluem o limite. Os operadores >= e <= incluem o limite.

3. If: executar quando for verdadeiro

int estoque = 8;
int quantidade = 3;

if (estoque >= quantidade)
{
    Console.WriteLine("Há estoque suficiente.");
}

Se a condição for falsa, esse bloco é ignorado. Depois da decisão, a execução continua na instrução seguinte. Use chaves para deixar claro quais instruções pertencem à condição.

4. If e else: dois caminhos

int idade = 17;

if (idade >= 18)
{
    Console.WriteLine("Pessoa maior de idade.");
}
else
{
    Console.WriteLine("Pessoa menor de idade.");
}

Somente um dos blocos será executado. Com idade 17, a saída é “Pessoa menor de idade.”. Com idade 18, o primeiro bloco é executado porque o limite está incluído.

5. Else if: várias faixas

double nota = 6.5;

if (nota < 0 || nota > 10)
{
    Console.WriteLine("Nota inválida.");
}
else if (nota >= 7)
{
    Console.WriteLine("Aprovado.");
}
else if (nota >= 5)
{
    Console.WriteLine("Recuperação.");
}
else
{
    Console.WriteLine("Reprovado.");
}

Nesta regra de exemplo, notas entre 5 e menos de 7 indicam recuperação. A cadeia é avaliada de cima para baixo e termina no primeiro bloco cuja condição for verdadeira. Por isso, a ordem das verificações importa.

Vários if independentes podem executar mais de um bloco. Uma cadeia if / else if / else escolhe apenas um caminho. Use condições independentes quando várias ações puderem acontecer juntas.

6. Operadores lógicos

OperadorRegraExemplo
&&E: as duas condições precisam ser verdadeirasidade >= 18 && possuiDocumento
||OU: pelo menos uma condição precisa ser verdadeiradia == "sábado" || dia == "domingo"
!NÃO: inverte o valor lógico!ocupado

Para expressar uma faixa, faça as duas comparações: nota >= 0 && nota <= 10. Não escreva 0 <= nota <= 10. Use parênteses quando misturar condições para tornar a intenção clara.

&& e || usam avaliação de curto-circuito. No E, se a primeira parte for falsa, a segunda não precisa ser avaliada. No OU, se a primeira parte for verdadeira, a segunda não precisa ser avaliada.

7. Validação e condições dentro de condições

int estoque = 10;
Console.Write("Quantidade desejada: ");
int quantidade;

if (int.TryParse(Console.ReadLine(), out quantidade))
{
    if (quantidade > 0 && quantidade <= estoque)
    {
        estoque = estoque - quantidade;
        Console.WriteLine($"Venda realizada. Restam {estoque} unidades.");
    }
    else
    {
        Console.WriteLine("Quantidade inválida ou estoque insuficiente.");
    }
}
else
{
    Console.WriteLine("Digite um número inteiro.");
}

A primeira decisão valida a conversão. A segunda verifica a regra da venda. Separar essas etapas ajuda a identificar por que uma entrada foi recusada.

8. Erros comuns e teste de limites

  • Não coloque ; logo depois de if (condicao): isso encerra a instrução e separa o bloco da condição.
  • Evite faixas sobrepostas e verifique a ordem dos else if.
  • Não use || para uma faixa que exige as duas condições simultaneamente.
  • Teste os valores imediatamente antes, no limite e depois do limite. Para idade >= 18, teste 17, 18 e 19.

Pratique

Leia uma idade e recuse valores negativos. Para as demais entradas, mostre “criança” até 11 anos, “adolescente” de 12 a 17 e “adulto” a partir de 18. Teste as fronteiras de cada faixa.
