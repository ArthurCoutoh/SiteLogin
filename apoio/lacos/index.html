Laços de repetição

1. O que é um laço?

É uma estrutura que executa um bloco várias vezes. Em vez de repetir o mesmo código manualmente, você define como começar, quando continuar e como avançar. Cada execução do bloco é uma iteração.

Um contador acompanha quantas repetições aconteceram. Um acumulador guarda um resultado construído ao longo das repetições, como a soma das notas de uma turma.

2. For: repetição com controle explícito

for (int contador = 1; contador <= 5; contador++)
{
    Console.WriteLine(contador);
}

A saída são os números de 1 a 5, um por linha. As três partes entre parênteses são:

  1. Inicialização: int contador = 1, executada uma vez.
  2. Condição: contador <= 5, verificada antes de cada execução.
  3. Atualização: contador++, executada depois do bloco.

Se a condição já começar falsa, o bloco não é executado. O contador declarado no cabeçalho pertence ao laço. Para contar regressivamente, use uma condição compatível e diminua o contador.

for (int contador = 5; contador >= 1; contador--)
{
    Console.WriteLine(contador);
}

3. Acumulador

int soma = 0;

for (int numero = 1; numero <= 4; numero++)
{
    soma = soma + numero;
}

Console.WriteLine($"Soma: {soma}"); // Resultado: 10.

A soma começa em zero fora do laço. Depois das quatro iterações, ela vale 1, 3, 6 e 10, respectivamente. Se você zerar o acumulador dentro do bloco, perderá o resultado das repetições anteriores.

4. While: verificar antes de executar

int contador = 1;

while (contador <= 3)
{
    Console.WriteLine($"Passo {contador}");
    contador++;
}

while testa a condição antes de entrar no bloco. Ele pode executar zero vezes. É útil quando a quantidade de repetições depende de uma condição, como aguardar uma entrada válida.

int idade;
Console.Write("Digite uma idade não negativa: ");

while (!int.TryParse(Console.ReadLine(), out idade) || idade < 0)
{
    Console.Write("Entrada inválida. Tente novamente: ");
}

Console.WriteLine($"Idade aceita: {idade}");

Se a conversão falhar ou a idade for negativa, o programa solicita outra entrada. Quando a conversão funciona e a idade é não negativa, a condição do laço fica falsa.

5. Do-while: executar pelo menos uma vez

int opcao = 0;

do
{
    Console.WriteLine("1 - Continuar");
    Console.WriteLine("2 - Sair");
    Console.Write("Escolha: ");

    if (!int.TryParse(Console.ReadLine(), out opcao))
    {
        opcao = 0;
        Console.WriteLine("Digite um número.");
    }
    else if (opcao != 1 && opcao != 2)
    {
        Console.WriteLine("Escolha 1 ou 2.");
    }
} while (opcao != 2);

A condição é verificada depois do bloco, por isso o menu aparece pelo menos uma vez. O ponto e vírgula após while (condicao); faz parte da estrutura do do-while.

6. Foreach: percorrer os elementos

string[] nomes = { "Ana", "Bruno", "Carla" };

foreach (string nome in nomes)
{
    Console.WriteLine(nome);
}

Um vetor guarda vários elementos de um mesmo tipo. foreach lê cada elemento sem exigir um índice manual. Use for quando precisar do índice ou quiser alterar os elementos pelo índice.

int[] notas = { 7, 8, 9 };

for (int indice = 0; indice < notas.Length; indice++)
{
    Console.WriteLine($"Posição {indice}: {notas[indice]}");
}

Os índices começam em zero. Para um vetor de tamanho 3, as posições válidas são 0, 1 e 2. A condição indice < notas.Length evita acessar uma posição inexistente.

7. Break e continue

for (int numero = 1; numero <= 10; numero++)
{
    if (numero == 3)
    {
        continue; // Pula o restante desta iteração.
    }

    if (numero == 6)
    {
        break; // Encerra o laço.
    }

    Console.WriteLine(numero);
}
// Saída: 1, 2, 4 e 5, um por linha.

break encerra o laço mais próximo. continue pula para o próximo ciclo de controle; no for, a atualização ainda acontece. Em um while, cuidado para não pular uma atualização necessária e deixar a condição sempre verdadeira.

8. Laços dentro de laços

int[,] matriz = { { 1, 2, 3 }, { 4, 5, 6 } };

for (int linha = 0; linha < matriz.GetLength(0); linha++)
{
    for (int coluna = 0; coluna < matriz.GetLength(1); coluna++)
    {
        Console.Write(matriz[linha, coluna] + " ");
    }
    Console.WriteLine();
}
// Saída:
// 1 2 3
// 4 5 6

O laço externo escolhe uma linha. Para cada linha, o laço interno percorre todas as colunas. GetLength(0) informa a quantidade de linhas e GetLength(1) a de colunas dessa matriz. No exemplo, o bloco interno executa 2 × 3 = 6 vezes.

9. Qual escolher?

LaçoUso comumPode executar zero vezes?
forContagem, índices e quantidade conhecidaSim
whileContinuar enquanto uma condição permitirSim
do-whileMenu ou ação que precisa ocorrer ao menos uma vezNão
foreachLer cada elemento de uma coleçãoSim, se a coleção estiver vazia

10. Erros comuns

  • Garanta que a condição possa ficar falsa; caso contrário, poderá ocorrer um laço infinito.
  • Confira se o contador aumenta ou diminui na direção correta.
  • Teste se o limite usa < ou <=, principalmente em vetores e matrizes.
  • Inicialize acumuladores antes do laço e use um contador separado para cada laço aninhado.
  • Em um teste de mesa, anote contador, condição e acumulador em cada repetição.

Pratique

Leia cinco números e calcule a soma com um for. Depois, use um while para continuar lendo números até o usuário digitar zero. Por fim, faça um menu com do-while que permita sair. Confira com entradas pequenas antes de ampliar os dados.
