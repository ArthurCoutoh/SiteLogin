APOIO 03 / C#

Switch Case

1. Para que serve?

switch seleciona um bloco a partir de uma expressão. No uso básico, ele compara um valor com alternativas definidas em case. É útil para menus: opção 1 cadastra, opção 2 consulta e opção 3 encerra.

if é conveniente para faixas e condições combinadas. Um switch com valores explícitos facilita a leitura quando você tem várias opções específicas. C# também permite padrões mais avançados em switch, mas os casos simples são suficientes para começar.

2. Estrutura

int opcao = 2;

switch (opcao)
{
    case 1:
        Console.WriteLine("Cadastrar.");
        break;
    case 2:
        Console.WriteLine("Consultar.");
        break;
    default:
        Console.WriteLine("Opção desconhecida.");
        break;
}

Nesse exemplo, a saída é “Consultar.”. A expressão entre parênteses é avaliada para selecionar o caso correspondente.

ParteO que faz
switch (opcao)Indica o valor usado para escolher o caminho.
case 1:Define uma alternativa para o valor 1.
break;Encerra o switch e continua após seu bloco.
default:Executa quando nenhum dos casos corresponde; é opcional, mas útil para entradas inesperadas.

3. Menu com entrada validada

Console.WriteLine("1 - Cadastrar");
Console.WriteLine("2 - Consultar");
Console.WriteLine("3 - Sair");
Console.Write("Escolha uma opção: ");

int opcao;
if (int.TryParse(Console.ReadLine(), out opcao))
{
    switch (opcao)
    {
        case 1:
            Console.WriteLine("Cadastro selecionado.");
            break;
        case 2:
            Console.WriteLine("Consulta selecionada.");
            break;
        case 3:
            Console.WriteLine("Saída selecionada.");
            break;
        default:
            Console.WriteLine("Escolha 1, 2 ou 3.");
            break;
    }
}
else
{
    Console.WriteLine("Digite uma opção numérica.");
}

Esse código mostra o menu uma vez. Para mantê-lo ativo, combine a decisão com um laço, como no exemplo a seguir. Validar a conversão é diferente de validar a opção: “abc” não é um inteiro; 9 é um inteiro, mas não pertence ao menu.

4. Menu que se repete

int opcao = 0;

do
{
    Console.WriteLine("1 - Mostrar mensagem");
    Console.WriteLine("2 - Sair");
    Console.Write("Opção: ");

    if (!int.TryParse(Console.ReadLine(), out opcao))
    {
        Console.WriteLine("Entrada inválida.");
        opcao = 0;
        continue;
    }

    switch (opcao)
    {
        case 1:
            Console.WriteLine("Bem-vindo!");
            break;
        case 2:
            Console.WriteLine("Encerrando...");
            break;
        default:
            Console.WriteLine("Escolha 1 ou 2.");
            break;
    }
} while (opcao != 2);

O break dentro de um caso encerra apenas o switch. Quem encerra o do-while é a condição opcao != 2, que fica falsa quando a opção é 2. O continue, usado antes do switch, passa para a verificação do laço sem executar o restante daquela repetição.

5. Vários casos com a mesma ação

int dia = 7;

switch (dia)
{
    case 6:
    case 7:
        Console.WriteLine("Fim de semana.");
        break;
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        Console.WriteLine("Dia útil.");
        break;
    default:
        Console.WriteLine("Informe um dia de 1 a 7.");
        break;
}

Aqui, a convenção do exemplo é 1 para segunda-feira e 7 para domingo. Rótulos consecutivos podem compartilhar o mesmo bloco. Em C#, um caso com instruções não passa automaticamente para o próximo: o bloco precisa encerrar seu fluxo, por exemplo com break.

6. Switch com texto

Console.Write("Digite abrir ou fechar: ");
string comando = (Console.ReadLine() ?? "").Trim().ToLowerInvariant();

switch (comando)
{
    case "abrir":
        Console.WriteLine("Abertura solicitada.");
        break;
    case "fechar":
        Console.WriteLine("Fechamento solicitado.");
        break;
    default:
        Console.WriteLine("Comando não reconhecido.");
        break;
}

Trim() remove espaços no início e no fim. ToLowerInvariant() padroniza as letras para minúsculas, para que “ABRIR” e “abrir” sejam tratados da mesma forma nesse menu.

7. Erros comuns

  • Não esqueça os dois-pontos após case e default.
  • Não repita o mesmo valor em dois casos.
  • Use casos compatíveis com o tipo da expressão: para um texto, escreva case "1":; para um inteiro, case 1:.
  • Não espere que break encerre todo o programa. Ele encerra o switch ou laço mais próximo ao qual se aplica.
  • Inclua uma resposta para opções não previstas.

Pratique

Crie um menu com 1 para somar dois números, 2 para subtrair e 3 para sair. Use switch e mantenha o menu ativo até a opção 3. Teste uma opção válida, uma opção fora da lista e um texto que não seja um número.
